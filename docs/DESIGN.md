# 設計（VAL Tracker）

Riot アカウントと連携する VALORANT のトラッカー。サイト一覧（Home Page）に Python のサイトとして載る。
書式・CI・サイトの約束は統括の [CONVENTIONS.md](https://github.com/AlstRafe/home-page/blob/master/docs/CONVENTIONS.md) に従う。

## 作り

- サーバー: Python（Flask）。`valtracker/` パッケージ。Home Page のサーバーが `valtracker.hosting:site` を読み込み、
  `/val` の下で配信する。単独でも `python -m valtracker` で動く（このPCでの確認用）
- 画面: サーバーで HTML を組み立てる（Jinja テンプレート）＋小さな素の JS（お気に入り・テーマ・読み込み中の表示）。
  npm は整形・チェックの道具だけ
- 4 言語（ja / ko / en-GB / zh-TW）、ダーク / ライト、スマホ幅（760px 以下）は下のタブバー
- 外部の CDN・フォントは読まない。エージェントやマップの画像もサーバーが取ってきて `instance/` にためて自分のアドレスで出す

| エージェント     | `/val/agents`         | 一覧と能力の説明（4 言語）                                              | 1    |
| 今日のショップ   | `/val/shop`           | 今日のスキン 4 つ・残り時間・値段（ナイトマーケットも）                 | 2    |
| 所持品           | `/val/collection`     | 持ち主の残高・スキン（武器別）・バディー・カード・スプレーなど          | 2 ✓  |
| エージェント進捗 | `/val/progress`       | エージェントごとのレベル・契約の進み具合                                | 2    |
| 対戦中           | `/val/live`           | いまの試合の相手と味方の戦績（ランク・最近の成績）                      | 3    |

## 使う外部の API

| 相手                                         | 使う所                                         | 必要なもの                                  |
| -------------------------------------------- | ---------------------------------------------- | ------------------------------------------- |
| [HenrikDev API](https://docs.henrikdev.xyz)  | ID 検索・ランク・試合の一覧と中身              | 無料の API キー（持ち主が取って設定画面へ） |
| [valorant-api.com](https://valorant-api.com) | エージェント・マップ・ランク・スキンの名前と絵 | なし（4 言語あり。英語は en-US を使う）     |
| Riot の非公式な内部 API（PD・GLZ）           | ショップ・所持品・エージェント進捗・対戦中     | Riot のログイン（ssid クッキー、下）        |

Riot 公式の API は VALORANT の戦績に正式な審査（本番キー）が要るので、まずは HenrikDev を使う。

## データの持ち方

- `instance/`（Git に入れない）: 設定（API キーなど）、外部 API の答えの一時保存、画像のキャッシュ
- お気に入り: 見ている人のブラウザ（localStorage）。登録なしで使える
- 外部 API の答えは数分ためて、同じ人を何度開いても呼びすぎない（HenrikDev のキーは呼べる回数に上限がある）
- Riot のログイン情報（段階2）は持ち主の分だけ、`instance/riot.json`（持ち主だけが読める）にだけ置く

## Riot のログイン（段階2、`valtracker/riot.py`）

Riot のサインインにはキャプチャがあるので、パスワードはサーバーに渡さない（2026-11-05 に持ち主が決定）。

1. 持ち主が PC のブラウザで Riot にログインし（「サインインしたままにする」）、開発者ツールで auth.riotgames.com の
   `ssid` クッキーを写して `/val/settings` に貼る（Cookie ヘッダーまるごとでもよい）
2. サーバーは要るたびに ssid で `auth.riotgames.com/authorize` を開き、1 時間のトークンを受け取る。Riot が返す新しい
   ssid（Set-Cookie）で保存し直すので、パスワード変更やログアウトまで貼り直さなくてよい
3. エンタイトルメントのトークン・puuid（userinfo）・シャード（riot-geo）を取り、PD の財布・ロードアウト・所持アイテム
   （種類ごと）を読む。90 秒ためる
4. 切れたら設定と所持品のページで「ログインが切れています」と出し、ssid は残す（もう一度通ることがある）

ログイン後に移ったアドレス（`playvalorant.com/opt_in#access_token=…`）を貼っても 1 時間だけ使える。
PD の答えの形は公開されていないので、読めなかったものは設定ページに「最後に読めなかったもの」として出す。

## 段階

1. 土台（共通ファイル・CI・サーバーの骨組み・画面の枠）、ID 検索の戦績＋お気に入り、エージェント
2. Riot ログイン → 今日のショップ・コレクション・エージェント進捗
3. 対戦中の相手の戦績
4. 遠隔エージェントピック（作るかどうかから決める）

## 公開（Home Page 側でやること）

このリポジトリでは変えられないので、Home Page プロジェクトに頼む。

- `sites.toml` に `[[site]]`（`mount = "/val"`、`python = "../VALORANT-Project"`、`entry = "valtracker.hosting:site"`）
- VM の `deploy/setup.sh`・`update.sh` のリポジトリ一覧に `valorant-project` を足し、`requirements.txt` を入れる
- `live.yml` の確認先に `/val/` を足す
